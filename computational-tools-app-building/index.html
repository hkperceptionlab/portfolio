I could describe an idea and use AI tools to help make something that worked. However, I often did not understand the code behind it. When an error appeared, I did not know what the message meant or which part I should change. This became a clear limit for me.

At the beginning of summer break in June 2026, I returned to Korea to prepare for my research internship with Professor WooJin Chung. Soon after I returned, I completed two Python courses on Coursera: Programming for Everybody (Getting Started with Python) and Python Data Structures.

The courses introduced me to variables, conditions, functions, loops, strings, files, lists, dictionaries, and tuples. I was still a beginner after finishing them, and I could not write a complete app by myself. Introduction to Programming

Programmer: Works as an intermediary between the hardware and the user.

A common challenge for a beginning Python programmer is understanding indentation and its role in Python syntax.

In the fetch stage, the fetch-execute cycle gets instructions from memory.

Output devices: screen, speakers, printer, DVD burner

Input devices: keyboard, mouse, touch screen

Central Processing Unit: a highly developed circuit with many transistors. It runs programs and always wonders, “What should I do next?” It is very dumb and very fast. It performs arithmetic and logical operations on data.

Main memory: fast, small, and temporary storage. Example: RAM

Secondary memory: slower, larger, and permanent storage. Examples: disk drive, memory stick

The machine language of a computer consists of 0s and 1s.

We write Python → it is translated into machine language → it runs using the main memory and CPU.

Pythonistas: people who use Python.

Guido van Rossum began developing Python in 1989.

Syntax error: It means that Python is lost because the code does not follow its rules.

Elements of Python

  1. Vocabulary / words: variables and reserved words
  1. Sentence structure: valid syntax patterns
  1. Story structure: constructing a program for a purpose
  1. Reserved words: words that cannot be used as variables or identifiers

Interactive: I type directly into Python one line at a time, and it responds.

Script: I enter a sequence of statements into a file using a text editor and tell Python to execute the statements in the file.

Chapter 2

Variables and Expressions

Constants are a big part of any programming language.

Constants:

  • Fixed values such as numbers, letters, and strings
  • The values of constants do not change
  • Numeric constants: 1, 3, 4, etc.
  • String constants use single quotes (') or double quotes (")

Variable name: a named place in memory where a programmer can store data and later get the data back by using the variable name.

Programmers choose the names of variables, such as x and y. They can change the value stored in a variable in a later statement.

Python variable name rules: A variable name must start with a letter or underscore. It can contain letters, numbers, and underscores.

Sentences or lines

Assignment statement: x = 2

Assignment with an expression: x = x + 2

Print statement: print(x)

Variable: x

Assignment operator: =

Arithmetic operator: +

Constant: 2

Function: print

Mnemonic variable names are descriptive names that are easier for people to understand.

A variable is a memory location used to store a value. The value stored in a variable can be changed by replacing the old value with a new one.

Assignment statement example: x = 3.9 * x * (1 - x)

  • We assign a value to a variable by using an assignment statement (=).
  • An assignment statement has an expression on the right side and a variable that stores the result on the left side.

Numerical expressions: Python uses symbols to express common math operations.

Addition: +

Subtraction: -

Multiplication: *

Division: /

Power: **

Remainder: %

Operator precedence, or order of evaluation: When we use several operators together, Python must know which one to do first.

Operator precedence rules, from highest to lowest:

  1. Parentheses
  1. Exponentiation
  1. Multiplication, division, and remainder
  1. Addition and subtraction
  1. Left to right when the operators have the same precedence

In Python, variables, literals, and constants have a type.

Python knows the difference between a number and a string. For example, + means addition when the values are numbers. It means concatenation when the values are strings.

We cannot add the number 1 to a string. We can ask Python about the type of something by using the type() function.

Types of numbers

  • Integers: whole numbers, such as -14, -2, 0, 1, and 100
  • Floating-point numbers: numbers with decimal parts, such as -2.5, 0.4, and 98.6

Type conversion: When an integer and a floating-point number are used in the same expression, Python usually converts the integer into a floating-point number. I can also control the conversion by using functions such as int() and float().

Regular division using / produces a floating-point result.

String conversion: I can use int() and float() to convert a string containing a number into an integer or floating-point number. I will get an error if the string does not contain the right numeric characters.

User input: The input() function tells Python to pause and read data from the user. The input() function returns a string.

Comments in Python: Anything after # is ignored by Python.

A comment can describe what will happen in a sequence of code or record who wrote the code and other information. It can also temporarily turn off a line of code.

Converting user input: If we want to read a number from the user, we must convert the input from a string into a number by using a type conversion function.

Chapter 5

Loops and Iteration

Repeated steps: Loops have iteration variables that change each time through a loop. These variables often move through a sequence of numbers or other values.

Breaking out of a loop

  • The break statement ends the current loop and moves to the statement immediately after the loop.
  • It works like a loop test that can happen anywhere inside the body of the loop.

The continue statement ends the current iteration, returns to the top of the loop, and starts the next iteration.

A simple definite loop: A definite loop has an iteration variable that changes each time through the loop. The variable moves through a sequence or set.

A simple definite loop example:

for i in [5, 4, 3, 2, 1]:

→ print(i)

print("Blastoff!")

  • The iteration variable moves through the ordered set.
  • The indented block of code runs once for each value in the sequence.
  • The iteration variable moves through all the values in the sequence.

Making “smart” loops: The idea is to learn something about the whole group of data while the code looks at only one item at a time.

  1. Set some variables to their starting values.
  1. For each item in the data, look for something or do something to the item and update a variable.
  1. Look at the variables after the loop ends.

Finding the largest value: If the current number is larger than the largest value found so far, it becomes the new largest value.

Counting in a loop: To count how many times a loop runs, we use a counter variable that starts at 0. We add 1 to it each time through the loop.

Summing in a loop: To add the values in a loop, we use a sum variable that starts at 0. We add each value to the sum as the loop runs.

Finding the average in a loop: An average combines the counting and summing patterns. After the loop ends, we divide the sum by the count.

Filtering in a loop: We use an if statement inside the loop to find or filter the values we want.

Searching with a Boolean variable: If we only want to know whether a value was found, we can use a variable that starts as False. It changes to True when the value is found.

Finding the smallest value: We can use a variable named smallest_so_far and compare each new value with it. At the beginning, the variable can be None because we have not seen a number yet. The first value then becomes the smallest value found so far.

The is and is not operators

The is operator checks whether two references point to the same object. It is different from ==, which checks whether two values are equal.

The is not operator checks whether two references do not point to the same object.

The is operator is often used with None, such as smallest is None.

Strings

We often read data as strings first and then parse and convert the data when needed. This gives us more control over errors or incorrect user input. Numbers entered by a user also begin as strings and must be converted.

Methods for looking inside strings

  1. We can get one character from a string by using an index inside square brackets.
  1. The index must be an integer and starts at 0.
  1. The index can also be an expression that produces an integer.

Python gives an error if we try to use an index beyond the end of a string.

The built-in len() function gives us the length of a string.

string → len() → number

Example:

0 1 2 3 4 5

Looping through strings

By using a while statement, an iteration variable, and the len() function, we can look at each letter in a string.

fruit = "banana"

index = 0

while index < len(fruit):

→ letter = fruit[index]

→ print(index, letter)

→ index = index + 1

A definite loop using for is simpler because the for loop takes care of the iteration variable.

The following loop goes through each letter in a string:

fruit = "banana"

for letter in fruit:

→ print(letter)

The following loop counts how many times the letter “a” appears:

word = "banana"

count = 0

for letter in word:

→ if letter == "a":

→ → count = count + 1

print(count)

Slicing strings

  • We can look at a continuous part of a string by using a colon.
  • The second number is one position beyond the end of the slice.
  • If the second number is beyond the end of the string, Python stops at the end.

Example:

s = "Monty Python"

print(s[0:4])

Result: Mont

It starts at position 0 but does not include position 4.

Using in as a logical operator

String methods

Searching a string

We use find() to search for a substring inside another string. It finds the position of the first occurrence. If the substring is not found, find() returns -1. String positions start at 0.

Files

Using open()

Basic form: open(filename, mode)

Example:

fhand = open("mbox.txt", "r")

The open() function returns a file handle that we can use to work with the file.

The filename is a string.

The mode is optional. We use "r" when we want to read a file and "w" when we want to write to a file. If we do not give a mode, Python normally opens the file for reading.

The newline character

  • We use a special character called a newline to show where a line ends.
  • We write it as \n inside a string.
  • A newline is still one character.

Example:

stuff = "hello\nworld!"

print(stuff)

Result:

hello

world!

A text file usually has a newline at the end of each line.

File handle as a sequence

A file handle opened for reading can be treated as a sequence of strings. Each line in the file is one string in the sequence. We can use a for statement to go through the lines.

Counting lines in a file

We can open a file for reading, use a for loop to read each line, count the lines, and print the total.

fhand = open("mbox.txt")

count = 0

for line in fhand:

→ count = count + 1

print("Line Count:", count)

Reading the whole file

We can use read() to read the whole file, including its newline characters, into one string.

Skipping with continue

We can use continue to skip lines that we do not want.

fhand = open("mbox-short.txt")

for line in fhand:

Lists

Algorithm: a set of rules or steps used to solve a problem.

Data structure: a way of organizing data in a computer.

Most variables hold one value. When we put a new value into the variable, the old value is replaced.

A collection allows us to put many values into one variable.

  • A list can contain strings, numbers, or other kinds of values.

We can get one element from a list by using an index inside square brackets.

The len() function takes a list and returns the number of elements in it. It can also give the length of other sequences.

The range() function produces a sequence of numbers from 0 to one less than the number we give it. We can use range() with a for loop and an integer index.

Chapter 9

Dictionaries

Collections allow us to keep more than one value in one variable. They also give us ways to find the different values.

Two types of collections

  • List: a collection of values stored by position
  • Dictionary: a collection of key-value pairs

A dictionary allows us to do fast database-like operations in Python.

Similar concepts in other programming languages

  • Associative arrays: Perl/PHP
  • Maps or hash maps: Java
  • Property bags: C#/.NET

Before Python 3.7, dictionaries did not always keep entries in the order they were added. Python 3.7 and later preserve the insertion order. However, the insertion order is not always the sorted order.

Python lists, dictionaries, and tuples are objects designed to be easy to use.

  • We add values to a list and find them by their position.
  • We add values to a dictionary with a key and find them again by using that key.

Dictionaries are similar to lists, but they use keys instead of position numbers.

Counting with a dictionary

One common use of a dictionary is counting. When we see a new name, we add it to the dictionary with a count of 1. If we see the same name again, we add 1 to its count.

Example:

counts = dict()

names = [“csev,” “cwen,” “csev,” “zqian,” “cwen”]

for name in names:

→ if name not in counts:

→ → counts[name] = 1

→ else:

→ → counts[name] = counts[name] + 1

print(counts)

The get() method

The get() method checks whether a key is already in the dictionary. If the key is not there, it gives us a default value.

Simplified counting example:

counts = dict()

names = [“csev,” “cwen,” “csev,” “zqian,” “cwen”]

for name in names:

→ counts[name] = counts.get(name, 0) + 1

print(counts)

Counting words

A common way to count words is:

  1. Split a line of text into words.
  1. Go through the words with a loop.
  1. Use a dictionary to keep the count for each word.

Loops and dictionaries

We can use a for loop to go through a dictionary. The loop goes through the keys, and we can use each key to find its value.

Example:

counts = {“chuck”: 1, “fred”: 42, “jan”: 100}

for key in counts:

→ print(key, counts[key])

Output:

chuck 1

fred 42

jan 100

Chapter 10

Tuples

Tuples are another kind of sequence. They work like lists because their elements have positions starting at 0. However, tuples cannot be changed after they are created. In this way, they are similar to strings.

  • Tuples are simpler than lists because Python does not need to make them changeable.
  • They can be useful for temporary values.
  • We can put a tuple on the left side of an assignment statement.
  • We can leave out the parentheses in some cases.
  • The items() method in a dictionary gives us key-value pairs as tuples.

Comparing tuples

Tuples can be compared. Python first compares the first element. If the first elements are equal, it moves to the second element. It continues until it finds a difference.

Examples:

(0, 1, 2) < (5, 1, 2)

True

(0, 1, 2000000) < (0, 3, 4)

True

(“Jones,” “Sally”) < (“Jones,” “Sam”)

True

(“Jones,” “Sally”) > (“Adams,” “Sam”)

True

Sorting lists of tuples

We can use tuples to make a sorted version of a dictionary. The items() method gives us the key-value pairs, and the sorted() function puts them in order.

Sorting by values instead of keys

If we make tuples in the form of (value, key), we can sort a dictionary by its values. We can use a for loop or list comprehension to create these tuples.

Example:

c = {“a”: 10, “b”: 1, “c”: 22}

print(sorted([(v, k) for k, v in c.items()]))

Output:

[(1, “b”), (10, “a”), (22, “c”)]

5. SAT vocabulary app

I began an early version during the Education App Building study in spring 2026. At that time, I decided that the same word should appear in several kinds of questions instead of only one flashcard. I returned to the project later and expanded it into the current version.

During the summer of 2026, I was also busy with a research internship, a pre-college class, AP assignments, and a leg injury. I could not always sit down and study for a long time, so I wanted something that I could use during small breaks.

I had used free study tools such as Quizlet, but I wanted to organize the words in a different way. I first focused on 500 words with multiple meanings. I noticed that knowing only the most common meaning of a word was not always enough for an SAT question. I made a four-step quiz so that I could meet the same word through context, synonyms, antonyms, and less obvious clues.

Later, I added a general vocabulary section because I also wanted to learn basic SAT words more carefully. The current version has two main sections: a general section with 991 SAT words divided into four parts, and a separate four-step quiz focused on 500 words with multiple meanings. It includes flashcards, two types of multiple-choice questions, fill-in-the-blank questions, spelling practice, and a random mix. When a user gets a word wrong or selects “Didn’t Know,” the app adds it to a missed-word list. The user can then review only those words with flashcards or another quiz. In the general vocabulary section, a word leaves the list after the user answers it correctly twice.

I did not use the app as regularly as I had hoped. Sometimes I now think that I should have opened it one more time during those short breaks. Still, making and using it helped me study. After school began, I shared the link with some classmates and younger students. Their reactions were more positive than I expected, and some of them said that they liked the different study modes. This was the first time I saw that a tool I had made for my own problem could also be useful to other students.

6. LINE UP

A. Why I made it

My whole family likes Son Heung-min. When he played in England, we sometimes watched his matches together at home. I enjoyed watching soccer before I began playing it at school.

I joined school soccer in tenth grade and continued in eleventh grade. I spent much of that time on the bench, but I was still part of the team.

During the summer after eleventh grade, I began making this app while thinking about my final year of high school. I planned to apply for a student sports manager position, and I thought I could use the app to support the team if I was selected.

In twelfth grade, I applied for the manager position. If I was not selected, I planned to return as a regular player, as I had done before. However, the teacher overseeing the sports program changed that term, and the school offered fewer sports activities and places than before. More students applied for the limited places, and I was not selected as a manager or as a player. I was very disappointed because I had expected to spend my final year with the team.

By that time, I had already made much of the app, so I continued working on it. I shared the link with some friends in my dorm and with Mr. Brooks, the team coach.

I did not want the app to be only a list of players. I wanted team members to check in, encourage one another, follow a short stretching routine, and try small soccer challenges. The app became another way for me to think about how someone could take part in a team, even when that person was not playing on the field.

B. What the app does

A player enters the app using a jersey number instead of a real name. The main page has a private mood check-in and a short team stretching activity. The mood stays only on that player’s device. Other people can see only the total number of team members who checked in that day.

I also made separate entrances for players and the coach. The app asks which role the person has, and the player and coach areas use different passwords and show different screens. Students can send a message to Mr. Brooks about soccer or something related to the team without adding their names. He can read these messages on the coach screen without seeing which student sent them. The coach screen also shows weekly check-in and warm-up counts and the team schedule.

Players can send short cheers to one another and build a personal streak. The app also has a weekly team mission based on check-ins and cheers. I added two short breathing activities for nervousness before a game.

The Team Stretch section has ten movements. A player can choose only a few or complete more of them. A character shows each movement while a voice explains what to do. The first voice sounded too much like a machine, so I later changed it to a more natural voice.

Our school mascot is the Knight, and it also appears on our athletic uniforms. This was why I called the small soccer game Knight’s Quest. The game has four levels that open one at a time.

C. Sharing team activity across phones

Most of the small apps I had made before saved information only on one device. I had wanted to learn how to connect an app to a shared database, and this project gave me a reason to try.

I wanted LINE UP to be easy to open on a phone. A cheer sent from one phone needed to appear on another phone, and everyone needed to see the same team check-in total. I connected the app to Supabase so that this information could be shared instead of remaining on only one person’s device.

Before sharing the app, I tested the check-ins, cheers, messages, and other functions many times. These tests left practice records in the shared data, so I cleared them before sending the app to other people. This allowed the students and Mr. Brooks to begin with a clean version instead of seeing my test records.

I sent the link to Mr. Brooks, the team coach, and to soccer players who lived in my dorm. When they opened the app on their phones, we could see one another’s team activity appear. I had only seen my own information in the apps I made before, so watching information move between different phones felt surprising to me.

At the same time, I did not want every kind of information to be shared. A player’s mood and personal streak stay only on that person’s device. The database receives the team check-in total, cheers, and other team activity, but it does not receive the individual mood choice.

7. What I learned

Vibe coding made me less afraid of turning an idea into something that worked. Before joining GPTers, I did not think that I could make an app. Later, I was able to choose the purpose and structure of a project, test each version, find problems, and keep asking for changes.

However, I did not write all of the code by myself. When something stopped working, I could describe the problem, but I did not always understand what had caused it. This limitation made me want to learn basic programming more seriously. Studying Python helped me begin to understand some of the logic behind the tools I had been using.

I also learned that making an app was not just about adding more features. I needed to think about privacy, whether people might misunderstand the results, and whether each idea was safe and useful. Sometimes I decided that it was better to remove an idea than to finish it.

I still have much more to learn about programming and about the science behind some of my activities. In the future, I would like to use these tools more carefully in cognitive science research. I also hope to find ways to present research through interactive or media art, so that people can experience an idea instead of only reading about it.
